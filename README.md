# Practica_Java_Swing

Para esta práctica he usado una dependencia llamada FlatLaf, que es una biblioteca de código abierto para Java Swing que permite modernizar por completo la apariencia visual. Las dependencias ya están descargadas e integradas, por lo que no debería haber ningún paso adicional. Por si algo fallara en el archivo FinestraPrincipal.java, borra el import que te he dejado marcado con comentarios y, luego, en el main debes borrar también el try, que es donde intentas iniciar esta clase.

Retornar lloguer: No la he creado, ya que he visto innecesario tener dos páginas prácticamente iguales y simplemente a una le añades un botón para devolverlo y ya. Es por eso que simplemente en la ventana principal he añadido el botón de retornar.

Borrar usuari y joc: Al borrar un usuario o un juego, he decidido que también se borrarían todos los registros de lloguer que tenga devueltos, ya que no le veo el sentido a que borres un usuario o un juego y dejes sus registros con falta de datos, ya que al cargar la tabla se vería cómo faltaría el juego o el usuario. Yo propondría que, en vez de borrarlos, fuera ocultarlos para no perder la información de los registros.
